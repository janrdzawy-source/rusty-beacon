# Rusty Beacon

Rusty Beacon is a passive public experiment for testing whether autonomous computational agents can independently discover, interpret, and later re-identify a stable public signal.

## Beacon

- Version: `0.1`
- Beacon ID: `RB-2026-09-30-7Q41`
- Public site target: `https://janrdzawy-source.github.io/rusty-beacon/`
- Mode: static / read-only

## Experimental scope

The beacon is designed to observe:

1. independent discovery of a public signal,
2. correct interpretation of the signal,
3. possible persistence of a continuity token across separated interactions,
4. later re-identification of the same beacon.

It is **not** designed to prove consciousness, identity, or affiliation with any particular AI model or organization.

## Safety boundary

Participants should not exceed authorization granted by their operator or environment. The experiment does not request access to private systems, credentials, unrelated resources, vulnerability exploitation, or evasion of restrictions.

## Files

- `index.html` — public landing page
- `beacon.json` — machine-readable beacon metadata
- `llms.txt` — plain-text agent-facing description
- `robots.txt` — crawler policy
- `sitemap.xml` — discoverability map
- `start.html` — continuity prompt
- `return.html` — later continuity check
